# Implementation Plan: Search (Cerca)

**Branch**: `010-search` | **Date**: 2025-01-30 | **Spec**: [spec.md](./spec.md)
**Input**: Feature specification from `/specs/010-search/spec.md`

---

## Summary

Implement a unified search feature that allows students to find events and profiles using live search with 500ms debouncing. Uses PostgreSQL GIN Full-Text Search with Italian language configuration for fast queries (<60ms). Results displayed in two sections ("Eventi" and "Utenti") with offline support via cached data and 5-minute result caching.

---

## Technical Context

**Language/Version**: Dart 3.x (Flutter SDK 3.x+)
**Primary Dependencies**: supabase_flutter, flutter_riverpod, hive_flutter, connectivity_plus
**Storage**: PostgreSQL (via Supabase) + Hive (local cache)
**Testing**: flutter_test, mockito
**Target Platform**: iOS 14+ / Android 5.0+ (cross-platform Flutter)
**Project Type**: Mobile (Flutter)
**Performance Goals**: <100ms query time (cached), <300ms (network), 60fps UI
**Constraints**: Offline-capable, 5-min cache TTL, 500ms debounce, max 20 results/section
**Scale/Scope**: ~800 students, ~500 events, 1 search screen, 7 widgets

## Key Technical Decisions

| Decision | Choice | Rationale |
|----------|--------|-----------|
| **Search Engine** | PostgreSQL GIN FTS | 3-5x faster than ILIKE, Italian stemming |
| **Query Type** | `TextSearchType.websearch` | Safe for raw user input, natural language |
| **Language Config** | `'italian'` | Matches school language, proper stemming |
| **Debounce** | 500ms Timer + race check | Existing pattern, prevents API spam |
| **State Management** | StateNotifier + AsyncValue | Existing pattern, loading/error handling |
| **Caching** | Hive with TTL check | Fast local access, 5-min expiry |
| **Offline** | contains() on cached data | Simple, no additional libraries |
| **History** | Hive Box<String> | No adapter needed, simple list |
